10. INTERAKTIVE FEATURES — BITTE MANUELL AUSPROBIEREN
═══════════════════════════════════════

Nach dem Einfügen dieser Demo nacheinander testen:

□ Embed-URL einfügen — z. B. YouTube-Link aus Abschnitt 7
□ Freihand zeichnen — Stift-Button in der Aktionszeile
□ Screenshot einfügen — Strg+Shift+Alt+S (oder Button)
□ Bild aus Zwischenablage — Strg+V
□ Datei per Drag & Drop auf den Editor ziehen
□ Audio-Aufnahme — im Anhänge-Bereich
□ Aufgabe erstellen — Cloud-Task-Button (Microsoft/Google)
□ Termin erstellen — Kalender-Button
□ Text markieren → „Auswahl als Aufgabe" / „Auswahl als Termin"
□ Editor Hell/Dunkel — Toggle oben rechts (wirkt auch auf X/Twitter-Embeds)
□ Kategorien setzen — im Seitenkopf (Outlook-Kategorien)
□ Im Kalender planen — Planungsdatum im Seitenkopf
□ PDF exportieren / Drucken — über Seitenmenü
□ Schnellnotiz — Strg+Shift+Alt+N
